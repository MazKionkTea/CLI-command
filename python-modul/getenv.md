| Command                                             | Deskripsi                                                                                                | Contoh                                                        |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| `import os`                                         | Mengimpor modul `os` yang menyediakan fungsi `getenv()`.                                                 | `import os`                                                   |
| `os.getenv()`                                       | Mengambil nilai environment variable berdasarkan nama variabel. Jika tidak ditemukan, hasilnya `None`.   | `os.getenv("USERNAME")`                                       |
| `os.getenv("NAMA_VARIABEL")`                        | Mengambil nilai environment variable tertentu.                                                           | `os.getenv("PATH")`                                           |
| `os.getenv("NAMA_VARIABEL", "default")`             | Mengambil nilai environment variable; jika tidak tersedia, menggunakan nilai default yang diberikan.     | `os.getenv("PORT", "8000")`                                   |
| `os.environ`                                        | Dictionary-like object yang berisi seluruh environment variable proses saat ini.                         | `print(os.environ)`                                           |
| `os.environ["NAMA_VARIABEL"]`                       | Mengambil nilai environment variable menggunakan indexing. Jika tidak ada, menghasilkan `KeyError`.      | `os.environ["PATH"]`                                          |
| `os.environ.get("NAMA_VARIABEL")`                   | Mengambil environment variable dengan metode `.get()`. Jika tidak ada, menghasilkan `None`.              | `os.environ.get("USERNAME")`                                  |
| `os.environ.get("NAMA_VARIABEL", "default")`        | Mengambil environment variable dengan nilai default jika variabel tidak ditemukan.                       | `os.environ.get("PORT", "8000")`                              |
| `os.environ["NAMA_VARIABEL"] = "nilai"`             | Membuat atau mengubah environment variable untuk proses saat ini dan proses anak yang dibuat setelahnya. | `os.environ["APP_ENV"] = "production"`                        |
| `os.putenv("NAMA_VARIABEL", "nilai")`               | Mengatur environment variable secara langsung melalui API OS.                                            | `os.putenv("APP_ENV", "production")`                          |
| `os.unsetenv("NAMA_VARIABEL")`                      | Menghapus environment variable dari environment proses.                                                  | `os.unsetenv("APP_ENV")`                                      |
| `del os.environ["NAMA_VARIABEL"]`                   | Menghapus environment variable melalui `os.environ`.                                                     | `del os.environ["APP_ENV"]`                                   |
| `if os.getenv("NAMA_VARIABEL"):`                    | Mengecek apakah environment variable memiliki nilai yang dianggap truthy.                                | `if os.getenv("DEBUG"): print("Debug aktif")`                 |
| `os.getenv("NAMA_VARIABEL") is None`                | Mengecek secara eksplisit apakah environment variable tidak ditemukan.                                   | `if os.getenv("API_KEY") is None: print("API key belum ada")` |
| `os.getenv("NAMA_VARIABEL", "default")`             | Pola umum untuk memberikan fallback ketika konfigurasi environment tidak tersedia.                       | `db = os.getenv("DATABASE_URL", "sqlite:///app.db")`          |
| `int(os.getenv("PORT", "8000"))`                    | Mengambil environment variable lalu mengonversinya menjadi integer.                                      | `port = int(os.getenv("PORT", "8000"))`                       |
| `float(os.getenv("TIMEOUT", "5.0"))`                | Mengambil environment variable lalu mengonversinya menjadi float.                                        | `timeout = float(os.getenv("TIMEOUT", "5.0"))`                |
| `os.getenv("DEBUG", "").lower()`                    | Mengambil environment variable dan mengubahnya menjadi lowercase, biasanya untuk pemeriksaan string.     | `debug = os.getenv("DEBUG", "").lower()`                      |
| `os.getenv("DEBUG", "false").lower() == "true"`     | Mengubah nilai environment variable berbentuk string menjadi pemeriksaan boolean sederhana.              | `debug = os.getenv("DEBUG", "false").lower() == "true"`       |
| `list(os.environ)`                                  | Mendapatkan daftar nama seluruh environment variable.                                                    | `print(list(os.environ))`                                     |
| `dict(os.environ)`                                  | Mengubah seluruh environment variable menjadi dictionary biasa.                                          | `env = dict(os.environ)`                                      |
| `os.environ.keys()`                                 | Mendapatkan seluruh nama environment variable.                                                           | `print(os.environ.keys())`                                    |
| `os.environ.values()`                               | Mendapatkan seluruh nilai environment variable.                                                          | `print(os.environ.values())`                                  |
| `os.environ.items()`                                | Mendapatkan pasangan nama dan nilai seluruh environment variable.                                        | `for key, value in os.environ.items(): print(key, value)`     |
| `os.environ.setdefault("NAMA_VARIABEL", "default")` | Mengatur nilai hanya jika environment variable tersebut belum tersedia.                                  | `os.environ.setdefault("APP_ENV", "development")`             |
| `os.environ.update({"KEY": "VALUE"})`               | Menambahkan atau memperbarui beberapa environment variable sekaligus.                                    | `os.environ.update({"APP_ENV": "prod", "DEBUG": "false"})`    |
